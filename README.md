# Axios Training Club — Program Library

A static website that lists every Training Club program with day-by-day cards, training-goal and equipment filters, a "What do you want to train?" search, and a "Get this program" button that links to each program's payment page.

No server, database or login. The site is plain HTML/JS in `site/`; Netlify publishes that folder (see `netlify.toml`).

## Folder layout

```
site/
  index.html     the page: program list, filters, search, detail view, and the tag tables
  engine.js      turns a program's data file into its card (weeks, rotations, progressions)
  links.js       payment / landing page URL for each program  ← edit this to add Kit links
  data/<slug>.js one file per program with its full prescription
tools/
  update-tags.js rebuilds the equipment + goal tags in index.html from the data files
  equipment.js   equipment rules (movement name → equipment); used by update-tags.js
  goals.js       goal rules; used by update-tags.js
  cards.js       prints every program as text, for checking:  node tools/cards.js site [slug ...]
  audit.js       flags odd data (load drops, missing "/ side", etc.):  node tools/audit.js site
  volt-id-map.json  Volt program ID → slug (only needed when refreshing data from Volt)
```

## Common changes

**Add or change a payment link**: in `site/links.js`, paste the URL for the program's slug:
```js
"warpig": "https://your-kit-page.kit.com/warpig",
```
The button shows up on that program's page as soon as the URL is filled in.

**Change wording, colors or layout**: everything visual lives in `site/index.html` (CSS at the top, page code at the bottom).

## How program data works

`index.html` holds these tables, all keyed by program slug:

| Table | What it is |
|---|---|
| `PROGRAMS` | `[name, slug, weeks, days/week, "HYP,STC,STR,MAX,UNLOAD"]`. Block codes are in the order they first appear. |
| `BLOCK_SEQ` | Block sequence across the weeks, e.g. `"A/B/A/B/A/B"`, `"AA/BB/CC"`, `"AAA/BBB/U"` (U = unload) |
| `EQUIP` | `[[equipment it needs], [other gear]]`, generated by `tools/update-tags.js` |
| `GOALS` | goals it supports, generated by `tools/update-tags.js` |
| `DETAILS` | hand-written cards for 3 programs (BLUDKRIEG, BELLATOR 1–2); every other program is built from `data/` |

Each `data/<slug>.js` file is a list of rows, one per movement:

```
[day, "ACTIVITY NAME", "W" or "C", group, order, "Movement name", "week:sets|week:sets|..."]
```
- `"W"` = workout, `"C"` = conditioning. Group 1/order 1 = A1, group 1/order 2 = A2, group 2/order 1 = B1…
- Sets for a week: `load~reps`, comma-separated. `3*65%~8-10` = 3 sets of 65% × 8–10.
  - Load: `65%` of 1RM, `BW`, `KB`, `MB`, `BAND`, `CARDIO`, or empty.
  - Reps: `8-10` reps, `30s` seconds, `20-40m` metres. A trailing `e` = each side. `r90` = 90 sec rest (cardio).
- A week of `=` means "same as the previous week listed"; an empty week means no sets saved.

## Adding or refreshing a program

1. Create or replace `site/data/<slug>.js` in the format above.
2. If it's new, add a `PROGRAMS` row (keep alphabetical), a `BLOCK_SEQ` entry, a `<script src="data/<slug>.js">` tag next to the others, and a `"<slug>": ""` line in `links.js`.
3. Run `node tools/update-tags.js` to rebuild equipment and goal tags.
4. Run `node tools/cards.js site <slug>` and check the card reads correctly.

## Goal rules (from tools/goals.js)

- **Muscle Gain**: Hypertrophy block and ≥30% of lifts in 10+ rep ranges
- **Strength**: Strength block, or main lifts at ~80%+ for ≤5 reps
- **Fat Loss**: lifting plus 2+ conditioning days
- **Weight Loss**: 3+ conditioning days, metabolic circuits or hard intervals
- **Aerobic Endurance**: 75+ min aerobic cardio per week
- **Fitness Maintenance**: 2–3 conditioning days, moderate loads, no circuits/hard intervals
- **Total Body Power**: ≥15% of lifts explosive
- **Mobility / Core Strength**: ≥20% of work is core/mobility
- **Metabolic Conditioning**: metabolic circuits or hard intervals
